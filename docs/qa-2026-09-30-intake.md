## Confirmed causes addressed

- Baseline Home created requirements without capturing a template; template upload was a separate path.
- Old DOCX requirement parsing assumed number/text were the first two columns. Intake now maps explicit source columns.
- A low-score unselected Word table could retain old answers in output. Exclusion now recognizes source-like tables independently of header-score threshold.
- Nested prefix tables made descendant row indices disagree with direct source row indices. Template/source/export use direct rows for the selected table.
- Replacing the shared template could delete the TOR original. The file deletion path retains an ID still used by torDocId.

## Limits

OCR is deferred for this intake scope. Scanned PDF pages without text are rejected; no model/API is called. PDF boundaries require preview validation, and mixed incompatible DOCX tables are selected as a compatible group. Cross-format layout remains approximate.
