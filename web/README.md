# TOR Comply notebook workspace

## ใช้งาน

1. เริ่มจาก **ตาราง Comply + แม่แบบ** เลือก DOCX/PDF/XLSX แล้วกดอ่านตาราง ตรวจ preview และเลือกคอลัมน์เลขข้อกับข้อกำหนด กดยืนยันคอลัมน์แล้วสร้างโครงการ ไฟล์เดียวเป็นต้นฉบับและแม่แบบ ช่องคำตอบ/ผล/อ้างอิงเก่าเริ่มใหม่ทั้งหมด หรือเลือกโหมด TOR ต้นฉบับเพื่อใช้ขั้นตอนเดิม
2. ตรวจและยืนยันข้อความ TOR แต่ละข้อก่อน Auto ตารางที่มีหลายตารางย่อยนำเข้ากลุ่มที่หัวคอลัมน์เดียวกันได้ PDF ต้องมี text layer; รอบนี้ไม่เพิ่ม OCR ในการนำเข้าตาราง หากขอบคอลัมน์อ่านผิดให้ปรับใน preview หรือใช้ DOCX/XLSX
2. เพิ่ม **สินค้า** (ยี่ห้อ/รุ่น) หรือ **บริการ** (ผู้ให้บริการ จุดให้บริการ รายละเอียด) แล้วจัดประเภทไฟล์หลักฐานเป็นสินค้า บริการ หรือคุณสมบัติผู้ยื่น ไฟล์หลักฐานที่ทำไฮไลต์ใช้ PDF
3. คลิกแถวตาราง เลือกรายการที่จะใช้ร่วมกัน ระบบจัดอันดับคำที่ตรงในเอกสารที่แนบและเปิด TOR/หลักฐานตามแถว
4. ใช้ “ค้นหลักฐานและเสนอผล” หรือ Auto เพื่ออ่านเหตุผลรายเงื่อนไข สามารถลากกรอบเองและใช้จุดเดียวร่วมกับข้ออื่นได้ เลขข้อบน PDF รวมไว้ในเครื่องหมายเดียว
5. หลักฐานสแกนใช้ OCR เฉพาะกรอบ แล้วตรวจข้อความที่นำมาอ้างก่อนยืนยันหรือส่งออก
6. อัปโหลดแม่แบบหนึ่งไฟล์ DOCX/PDF/XLSX ตรวจการจับคู่หัวคอลัมน์ แล้วส่งออก PDF, Word หรือ Excel
7. “สำรองโครงการ” สร้าง .torproj รวม TOR หลักฐาน แม่แบบ ไฮไลต์ คำตอบ และสถานะ นำเข้าจากหน้าแรกเป็นโครงการใหม่ โดยไม่เขียนทับโครงการเดิม

## กฎและผลตัดสิน

- โหมดหลักเป็นตรวจเองหรือ Auto และเปลี่ยนเฉพาะข้อได้
- TOR/แม่แบบไม่อยู่ในดัชนีหลักฐานและใช้ยืนยันผลไม่ได้
- ตรวจ keywords, คำปฏิเสธ, หน่วยบิต/ไบต์, ค่าขั้นต่ำ/สูงสุด และคุณสมบัติที่ต้องตรง มีหน่วย/ศัพท์พื้นฐานสำหรับ Internet, Network, Server, CCTV, Security
- 25G ไม่ยืนยันว่ารองรับ 10G ต้องมีค่าหรือข้อความยืนยันความสามารถนั้น
- หลักฐานต้องครบทุกรายการที่เลือกใช้ร่วมกัน ข้อมูลที่ขัดแย้งหรือยังพิสูจน์ไม่ได้คงสถานะรอตรวจ
- กฎใช้การเทียบข้อความและเงื่อนไขที่รองรับ ไม่ได้พิสูจน์ความถูกต้องของหนังสือรับรองหรือความสามารถส่งมอบจริง ไม่มีการเรียกโมเดล AI ในรุ่นนี้

## รูปแบบและข้อจำกัดที่แสดงในแอพ

- เน้นโน้ตบุ๊ก หน้าทำงานกว้างขั้นต่ำ 1080px ปรับความกว้างสามช่องได้
- PDF/DOCX รักษารูปแบบแม่แบบเท่าที่อ่านได้; native DOCX เก็บตารางและหัว–ท้ายหน้าเดิม การข้ามชนิดไฟล์เป็นการจัดหน้าใหม่ ตรวจ preview/หัวคอลัมน์ก่อนส่งออก
- Excel เป็นตารางแก้ไข/กรองได้ ไม่มีการรวมเซลล์ในแถวข้อมูล
- แม่แบบ PDF อ่านโครงจากหน้าแรก หากอ่านไม่ครบต้องกำหนดหัวคอลัมน์ในหน้าตั้งค่า; ไม่ใช้คำตอบเก่าเป็นข้อมูลหรือหลักฐาน
- ตาราง Comply PDF อ่านข้อมูลหลายหน้าโดยใช้ขอบคอลัมน์และเส้นตาราง พร้อมแจ้งเมื่อข้อความคร่อมคอลัมน์ที่เลือก; DOCX/XLSX คงตำแหน่งคอลัมน์แม้สลับลำดับหรือมีเซลล์ว่าง
- TOR DOCX แสดงข้อความข้อกำหนดในช่องต้นฉบับและดาวน์โหลดไฟล์เดิมได้ ไม่มีการอ้างเลขหน้า PDF ที่ไม่มีอยู่จริง
- PDF หลักฐานที่หมุนหน้ามีข้อจำกัดในการ export annotation ระบบแจ้งก่อนสร้างไฟล์
- ไฟล์เดี่ยวจำกัด 40 MB; โครงการสำรองรวมไฟล์ต้นฉบับไม่เกิน 160 MB ข้อมูลในเว็บไซต์อาจหายหากล้าง browser storage ต้องสำรองเป็นระยะ
- ฟอนต์ PDF ใช้ Noto Sans Thai และ Helvetica รูปแบบการตัดบรรทัดอาจต่างจาก Microsoft Word

## พัฒนา

Node.js 22:
~~~sh
cd web
npm install
npm test
npm run build
npm run dev
~~~
