# TOR Comply Assistant

เว็บ React/Next.js สำหรับ Presales บนโน้ตบุ๊ก โค้ดอยู่ใน [web/](web/) โครงการและไฟล์เก็บในเบราว์เซอร์เครื่องนั้น ใช้กฎในโค้ด ไม่มี AI API และไม่มีการซิงก์เอกสารขึ้นเซิร์ฟเวอร์

หน้าทำงานเห็นตาราง Comply, TOR และหลักฐานพร้อมกัน รองรับสินค้า/บริการที่ใช้ร่วมกันหลายรายการ หลักฐานหลายข้อร่วมกัน โหมดตรวจเอง/Auto ตามกฎ แม่แบบ DOCX/PDF/XLSX และส่งออกตารางทั้ง PDF/DOCX/Excel

สำรองและย้ายงานด้วยไฟล์ .torproj ซึ่งรวมต้นฉบับทั้งหมด รายละเอียดการใช้งานและข้อจำกัดอยู่ใน [web/README.md](web/README.md)
