# TOR Comply

เว็บแอพสำหรับ Presales ทำตาราง Comply TOR ราชการไทยบนเครื่องผู้ใช้ ข้อมูลโครงการอยู่ใน `%LOCALAPPDATA%\TORComply` และเซิร์ฟเวอร์เปิดเฉพาะ `127.0.0.1` ไม่มีการส่ง TOR หรือเอกสารหลักฐานไปยัง AI API

## เริ่มใช้งานบนเครื่องนี้

เปิดโฟลเดอร์แอพแล้วดับเบิลคลิก `run.cmd` หรือเปิด Command Prompt ในโฟลเดอร์นั้นแล้วรัน:

```bat
run.cmd
```

เปิด `http://127.0.0.1:8765` บนโน้ตบุ๊ก หน้าจอปรับตามขนาดมือถือและโน้ตบุ๊ก แต่การเปิดจากโทรศัพท์จริงต้องมีการติดตั้งแอพบนเซิร์ฟเวอร์ที่โทรศัพท์เข้าถึงได้ก่อน ค่าเริ่มต้นแบบ local นี้ไม่เปิดรับการเชื่อมต่อจากเครือข่าย

repo นี้ใช้แอพ Python local แทน Next.js MVP เดิม ลิงก์ Vercel เดิมไม่ใช่แอพเวอร์ชันนี้ และไม่ควรนำเซิร์ฟเวอร์ local ไปเปิดบนเครือข่ายก่อนเพิ่มการยืนยันตัวตนและที่เก็บข้อมูลที่เหมาะสม

## ขั้นตอน

1. สร้างโครงการและนำเข้า TOR แบบ PDF/DOCX ระบบแยกข้อที่มีเลขข้อให้ตรวจแก้ PDF สแกนใช้ OCR ไทย/อังกฤษทีละหน้า จากนั้นตรวจและแก้ข้อความก่อนเพิ่มลงเช็กลิสต์
2. เพิ่มสินค้า/บริการที่เสนอ แล้วอัปโหลดเอกสารหลักฐาน PDF ระบบแสดงเอกสารที่มีคำตรงกันเป็นตัวช่วยค้นหา โดยไม่ตัดสินผล Comply
3. เลือกข้อ TOR และเอกสาร ลากกรอบบนหน้า PDF ระบุเลขหน้าที่พิมพ์ในเอกสาร แล้วบันทึกจุดอ้างอิง
4. เขียนรายละเอียดที่เสนอและยืนยันผลเปรียบเทียบแต่ละข้อ ดาวน์โหลดตาราง `.xlsx` สี่คอลัมน์และสำเนา PDF ที่ไฮไลต์สีเหลืองพร้อมเลขข้อสีแดง

ระบบไม่ยอมบันทึกผล `ตรงตามข้อกำหนด` ถ้ายังไม่มีรายละเอียดที่เสนอและจุดอ้างอิง การแก้ข้อความ TOR หลังตัดสินผลจะคืนสถานะเป็น `รอตรวจสอบ`

## ขอบเขตและข้อควรตรวจ

- อัปโหลดได้ไม่เกิน 40 MB ต่อคำขอ เอกสารหลักฐานที่ทำเครื่องหมายต้องเป็น PDF
- OCR และการแยกเลขข้ออาจอ่านผิด โดยเฉพาะภาพสแกนคุณภาพต่ำ ต้องเทียบกับ TOR ต้นฉบับก่อนยืนยัน
- เลขหน้า PDF และเลขหน้าที่พิมพ์ในเอกสารถูกเก็บแยกกัน เพราะไฟล์ตัวอย่างมีเลขหน้าต่างกัน
- เอกสารทางการค้าและข้อมูลราคาไม่ได้ถูกอ่านหรือเติมอัตโนมัติ ผู้ใช้เป็นผู้เลือกสินค้า เขียนรายละเอียดที่เสนอ และยืนยันผล
- ระบบยังไม่ค้นเว็บผู้ผลิตหรือดึง datasheet อัตโนมัติ ต้องเพิ่ม PDF ลงคลังเอกสารของโครงการก่อนจึงจะมีคำแนะนำจากคำที่ตรงกัน
- เซิร์ฟเวอร์ใช้ Python 3.11 จาก Codex runtime ที่มี `pdfplumber`, `pypdf`, `python-docx`, `openpyxl`, `reportlab` และใช้ Node/Tesseract.js ที่มีบนเครื่องนี้ การย้ายไปเครื่องอื่นต้องติดตั้ง dependencies เหล่านี้แบบ user scope

## ตรวจการทำงาน

```bat
"%USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" -m unittest discover -s tests -v
node --check app.js
node --check ocr.js
```

สี `#FF0038` และ `#262629` กับโลโก้นำจาก `1-to-all_Brand Manual (final).pdf` หน้า 9 และ 13 ของไฟล์ที่ผู้ใช้ให้ไว้ ฟอนต์แบรนด์อังกฤษไม่ได้ติดตั้งบนเครื่องนี้ จึงใช้ฟอนต์ระบบสำหรับข้อความไทย โครงตารางและรูปแบบไฮไลต์อ้างอิงไฟล์ใน `Example TOR` โดยไม่มีการคัดลอกเอกสารลูกค้ามาไว้ในแอพ ไฟล์ OCR ภาษาไทย/อังกฤษมาจาก [Tesseract tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast) และมีใบอนุญาตใน `ocr-data/LICENSE`; การเรียก OCR ใช้ [Tesseract.js](https://github.com/naptha/tesseract.js/blob/master/docs/api.md) ภายในเครื่อง
