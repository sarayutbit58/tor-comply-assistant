# TOR Comply Assistant

แอพ React/Next.js สำหรับ Presales ทำ Comply TOR ราชการไทย โค้ดแอพอยู่ใน [`web/`](web/) โดยข้อมูลโครงการและไฟล์ TOR/PDF เก็บในเบราว์เซอร์ของอุปกรณ์ที่ใช้งาน ไม่มีการส่งเอกสารไปยังเซิร์ฟเวอร์หรือเรียก AI API แบบเสียเงิน

ฟีเจอร์หลัก: นำเข้า TOR PDF/DOCX, OCR หน้า PDF สแกนทีละหน้า, เช็กลิสต์ข้อกำหนด, คลังสินค้าและเอกสาร, ไฮไลต์ PDF พร้อมเลขข้อ, และส่งออก Word/Excel/PDF ดูวิธีใช้งานและข้อจำกัดใน [web/README.md](web/README.md)

## พัฒนา

```sh
cd web
npm install
npm run test
npm run build
npm run dev
```

แอพนี้เป็นเว็บที่ปรับขนาดสำหรับโทรศัพท์และโน้ตบุ๊ก ข้อมูลไม่ซิงก์ข้ามอุปกรณ์ ผู้ใช้ต้องตรวจ OCR และยืนยันผล Comply เอง
